**目前没有附上真实图片或视频，作品集中的“待上传”是明确的空位，不是演示成果。** 后续由项目参与者自行准备、确认权利并脱敏后添加；不生成伪造的工作站照片、界面截图或性能结果。

建议未来按以下位置整理素材：

```text
assets/
├── screenshots/
│   ├── workstation.*       # 实体工作站、双屏与采集外设
│   ├── patient-screen.*    # 患者数字人与流程界面
│   └── staff-screen.*      # 医助操作、采集回看
├── demo/
│   └── collection-demo.*   # 虚构/获授权流程素材（非真实患者）
└── diagrams/
    └── ...                 # 将 Mermaid 转成发布版图片时再放
```

这些是**未来文件命名示意**，当前文件并不存在，README 不使用这些路径插入失效的图片。

正式上传前至少检查：医院/合作机构授权、患者与医助个人信息、屏幕上的真实病历、地点/日期/设备编号、内部 URL、账号、文件路径、算法权利归属和宣传措辞。未经临床验证不能把画面说明写成自动诊断成果。

如果视频较大，优先放经批准的视频平台或使用合适的 GitHub Releases/外链，再在 README 添加有意义的缩略图和说明；避免把大型录像直接反复提交进 Git 历史。

**发布流程**：先在私有母库审阅内容 → 确认公开范围 → 再向独立招聘仓库提交 PR。不要从私有项目仓库自动镜像任何素材。
